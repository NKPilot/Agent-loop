**DynamicToolCreator 类：**

构造函数：
```python
def __init__(
    self,
    registry: ToolRegistry,
    bus: EventBus,
    session_id: str,
    sandbox: SandboxExecutor,
    persistence: ToolPersistenceManager,
):
    self._registry = registry
    self._bus = bus
    self._session_id = session_id
    self._sandbox = sandbox
    self._persistence = persistence
    self._pending_confirmations: dict[str, tuple[asyncio.Event, dict | None]] = {}
```

核心方法 `generate_tool(name, description, code, test_code, language, param_schema) -> ToolResult`：

1. **Stage 0 — 计算 tool_id 和基本校验**：`tool_id = f"dynamic.{hashlib.sha256(code.encode()).hexdigest()[:8]}_{name}"`。校验 language 是 "python" 或 "bash"。校验 param_schema 是合法 JSON（json.loads(json.dumps(param_schema)) 能成功）。失败返回 ToolResult.error。

2. **Stage 1 — 语法检查**：
   - Python：`ast.parse(code)` 捕获 SyntaxError → 返回 ToolResult.error(f"语法检查失败: {具体错误信息}") 
   - Bash：`subprocess.run(["bash", "-n"], input=code, capture_output=True, text=True, timeout=10)` → 非零退出 → 返回 ToolResult.error(f"Bash 语法检查失败: {stderr}")

3. **Stage 2 — 危险扫描**：
   - Python：`DangerousModuleScanner().scan(code)` → 得到 risk_flags 列表
   - Bash：正则扫描危险命令（`rm -rf /`, `dd if=`, `mkfs`, `:(){ :|:& };:`, `curl.*|.*sh`, `wget.*|.*sh`, `/dev/sd`, `chmod 777 /`, `> /dev/sda` 等）。实现为 `_scan_bash_danger(code) -> list[dict]`
   - 扫描结果保存在变量 risk_flags 中，供 Stage 3 使用。Stage 2 本身不失败（即使检测到危险模块也继续——由用户决定是否批准）

4. **Stage 3 — 用户确认（EventBus 暂停，D-04 无超时）**：
   - 生成 `confirmation_id = str(uuid.uuid4())[:8]`
   - 创建 `asyncio.Event()` 存入 `_pending_confirmations[confirmation_id]`
   - 发布事件：
     ```python
     await self._bus.publish("tool_creation_requested", {
         "event_type": "tool_creation_requested",
         "session_id": self._session_id,
         "step_num": 0,  # 由 FSM 层在消费时覆盖
         "confirmation_id": confirmation_id,
         "tool_name": name,
         "tool_id": tool_id,
         "description": description,
         "code": code,
         "language": language,
         "risk_flags": risk_flags,
         "test_code": test_code,
         "param_schema": param_schema,
         "timestamp": datetime.now(timezone.utc).isoformat(),
     })
     ```
   - `await wait_event.wait()` (无 asyncio.wait_for——D-04 无超时)
   - 检查响应：`if config is None or not config.get("approved"): return ToolResult.error("用户拒绝创建工具")`
   - 从 config 提取 `persistence_level` 和 `extra_dirs`

5. **Stage 4 — 沙箱自测**：
   - 合并 code + test_code 为完整测试脚本：
     - Python：`full_code = code + "\n\n# --- Self-Test ---\n" + test_code`
     - Bash：`full_code = code + "\n\n# --- Self-Test ---\n" + test_code`
   - 创建沙箱工作目录：`sandbox_dir = tempfile.mkdtemp(prefix="tool_test_")`
   - 调用：`test_result = await self._sandbox.execute(full_code, language, working_dir=sandbox_dir, extra_dirs=config.get("extra_dirs", []))`
   - 发布自测结果事件：
     ```python
     await self._bus.publish("tool_creation_test_result", {
         "event_type": "tool_creation_test_result",
         "session_id": self._session_id,
         "tool_name": name,
         "status": test_result["status"],
         "output": test_result["output"],
         "error": test_result.get("error"),
         "duration_ms": test_result["duration_ms"],
         "timestamp": datetime.now(timezone.utc).isoformat(),
     })
     ```
   - 自测失败或超时 → `return ToolResult.error(f"自测{状态}: {output}")`
   - 清理临时目录

6. **Stage 5+6 — 持久化 + 注册**：
   - 构造 ToolMetadata：
     ```python
     meta = ToolMetadata(
         name=tool_id,
         description=description,
         permission_level=PermissionLevel.MODERATE,  # 动态工具永不 SAFE（v1.1 决策）
         timeout=30.0,
         param_schema=param_schema,
         func_ref=self._make_func_ref(tool_id, code, language, config),
         is_dynamic=True,
         tags=["dynamic", f"lang:{language}"] + ([f"persist:{persistence_level}"] if persistence_level != "session" else []),
     )
     ```
   - 注册到内存（D-06：确认后立即注册）：
     `self._registry.register_meta(meta, is_dynamic=True)`
   - 持久化（D-06：沙箱/项目级在首次执行成功后才写文件）：
     ```python
     if persistence_level != "session":
         meta_dict = {"name": name, "description": description, "language": language, "param_schema": param_schema, "persistence": persistence_level}
         self._persistence.save(name, code, language, persistence_level, meta_dict)
     ```
   - 发布 tool_created 事件：
     ```python
     await self._bus.publish("tool_created", {
         "event_type": "tool_created",
         "session_id": self._session_id,
         "step_num": 0,
         "tool_name": name,
         "tool_id": tool_id,
         "persistence": persistence_level,
         "timestamp": datetime.now(timezone.utc).isoformat(),
     })
     ```
   - 返回 `ToolResult.success(data=f"工具 {tool_id} 已创建并注册（{persistence_level}级持久化）", duration_ms=...)`

7. **确认机制方法**：
   - `respond(confirmation_id: str, approved: bool, config: dict)` — 由 API 端点调用；查找 _pending_confirmations[confirmation_id]，存储 config，event.set()

8. **`_make_func_ref(tool_id, code, language, config) -> Callable`** — 构造动态工具的可调用对象（func_ref）：
   - 返回一个 async 函数，该函数接受 `**kwargs`，内部：
     - 将 kwargs 序列化为 JSON 并写入临时文件
     - 调用 `SandboxExecutor.execute()` 在子进程中执行工具代码（code）+ 参数 JSON 文件
     - 返回子进程 stdout 作为工具结果
   - func_ref 是独立的 async 函数，不持有 DynamicToolCreator 或 Session 引用（Pitfall 3 防护）
   - Phase 8 实现基础版本：func_ref 内部创建临时 SandboxExecutor 实例执行

注意：generate_tool 方法设计为同步定义但内部使用 async/await，以便 ToolExecutor 正确调用。返回值是 ToolResult。

```python
async def _generate_tool_impl(
    name: str,
    description: str,
    code: str,
    test_code: str,
    language: str,
    param_schema: dict,
) -> ToolResult:
    """Agent 调用此工具提交 Python/Bash 代码以创建新的动态工具。"""
    return await creator.generate_tool(
        name=name,
        description=description,
        code=code,
        test_code=test_code,
        language=language,
        param_schema=param_schema,
    )
```

然后用 @tool 装饰：
```python
generate_tool_fn = tool(
    name="generate_tool",
    description="提交 Python 或 Bash 代码创建新的动态工具。系统会自动进行语法检查、安全扫描，然后弹出确认窗口供用户审批。通过审批和自测后，工具将被注册到系统中。",
    permission_level=PermissionLevel.MODERATE,
    timeout=120.0,  # 整个工具创建管道可能需要较长时间（含用户确认等待+自测执行）
    tags=["dynamic", "meta"],
)(_generate_tool_impl)
```
