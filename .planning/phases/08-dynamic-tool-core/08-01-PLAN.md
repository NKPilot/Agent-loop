1. ToolCreationRequested — event_type="tool_creation_requested"，字段：step_num: int, confirmation_id: str, tool_name: str, tool_id: str, description: str, code: str, language: Literal["python","bash"], risk_flags: list[dict], test_code: str, param_schema: dict
2. ToolCreationConfirmed — event_type="tool_creation_confirmed"，字段：step_num: int, confirmation_id: str, tool_name: str, persistence: Literal["session","sandbox","project"], extra_dirs: list[str] = []
3. ToolCreationRejected — event_type="tool_creation_rejected"，字段：step_num: int, confirmation_id: str, tool_name: str
4. ToolCreationTestResult — event_type="tool_creation_test_result"，字段：tool_name: str, status: Literal["passed","failed","timeout"], output: str, error: str | None = None, duration_ms: float
5. ToolCreated — event_type="tool_created"，字段：step_num: int, tool_name: str, tool_id: str, persistence: Literal["session","sandbox","project"]
6. ToolCreationFailed — event_type="tool_creation_failed"，字段：step_num: int, tool_name: str, stage: str, error_message: str

将 6 个新事件加入 Event 联合类型（位置不限，追加在 AgentCallEnd 之后即可）。
