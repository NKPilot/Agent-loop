**DangerousModuleScanner(ast.NodeVisitor)**：
- FORBIDDEN_IMPORTS 集合：os, subprocess, sys, ctypes, cffi, mmap, gc, code, types, marshal, pickle, imp, importlib, pdb, bdb, inspect, multiprocessing, socket, requests, httpx, urllib, http, signal, tracemalloc, faulthandler, traceback
- FORBIDDEN_CALLS 集合：eval, exec, compile, __import__, breakpoint, open
- BYPASS_PATTERNS 集合：__subclasses__, __bases__, __globals__, __code__, __traceback__, tb_frame, f_back
- severity_map：FORBIDDEN_IMPORTS 中 os/subprocess/socket/ctypes → "high"；sys/importlib/multiprocessing → "medium"；其余 → "low"。FORBIDDEN_CALLS 中 eval/exec/compile/__import__ → "high"；其余 → "medium"。BYPASS_PATTERNS → "high"
- scan(code: str) 方法：ast.parse(code) → self.visit(tree) → 返回 list[dict]（每个元素 {"type": "import"|"call"|"attribute", "name": str, "message": human-readable 中文解释, "severity": "high"|"medium"|"low", "line": int}）
- visit_Import(node)：检查每个 alias.name 是否在 FORBIDDEN_IMPORTS 中
- visit_ImportFrom(node)：检查 node.module 是否在 FORBIDDEN_IMPORTS 中
- visit_Call(node)：检查 func 是否为 Name(id=禁止名称) 或 Attribute(attr=禁止名称)
- visit_Attribute(node)：检查 attr 是否在 BYPASS_PATTERNS 中
- 每个 detect 调用 self.generic_visit(node) 确保遍历完整 AST

**SandboxExecutor**：
- __init__(self, timeout: float = 30.0, memory_limit_mb: int = 512)
- async execute(code: str, language: str, working_dir: str | None = None, extra_dirs: list[str] | None = None) → dict：{"status": "passed"|"failed"|"timeout", "output": str, "error": str|None, "duration_ms": float}
  - Python：用 tempfile.mkdtemp 创建临时目录 → 写入 code 到 script.py → subprocess.run([sys.executable, script.py], cwd=working_dir, timeout=self.timeout, capture_output=True, text=True, env={**os.environ, "SANDBOX_DIR": str(working_dir)}, preexec_fn=self._set_limits on Unix)
  - Bash：写入 code 到 script.sh → subprocess.run(["bash", script.sh], ...)
  - _set_limits()：resource.setrlimit(resource.RLIMIT_CPU, (timeout, timeout)); resource.setrlimit(resource.RLIMIT_AS, (memory_limit_mb * 1024 * 1024, memory_limit_mb * 1024 * 1024)); resource.setrlimit(resource.RLIMIT_NPROC, (50, 50))
  - 返回结构化 dict；子进程超时捕获 subprocess.TimeoutExpired → status="timeout"
  - 执行后清理临时目录（shutil.rmtree）
  - 注意：preexec_fn 仅在 Unix 平台使用（WSL2 兼容）；非 Unix 跳过 resource 限制
