**B. 新增 `_build_cmd()` 方法** — 构建平台特定命令（per D-02, RESEARCH Pattern 1）：
```python
@staticmethod
```

```python
@staticmethod
```

- 逐级向上解析存在的父目录，拼接剩余部分

**D. 新增 `_validate_path()` 方法** — 路径白名单校验（per D-03, RESEARCH Pattern 2）：
```python
@staticmethod
def _validate_path(path: str, allowed_roots: list[str]) -> bool:
```
- 定义模块级常量 `DENY_PATTERNS = ["/etc", "/proc", "/sys", "/dev", os.path.expanduser("~/.ssh"), os.path.expanduser("~/.gnupg"), os.path.expanduser("~/.aws")]`

**F. 新增 `_classify_violation()` 静态方法** — 分类违规类型：
```python
@staticmethod
def _classify_violation(stderr: str) -> str | None:
```
- 检查 stderr 中是否包含 `"Network is unreachable"` → 返回 `"network_attempt"`
- 检查是否包含 `"Resource temporarily unavailable"` → 返回 `"process"`（RLIMIT_NPROC）
- 检查是否包含 `"Cannot allocate memory"` 或 `"MemoryError"` → 返回 `"memory"`
- 检查是否包含 SIGXFSZ 相关错误 → 返回 `"file_size"`
- 否则返回 None

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM 生成代码 → SandboxExecutor | 不可信代码通过 sandbox 执行，沙箱提供隔离边界 |
| 子进程 → 宿主机文件系统 | 子进程仅能访问白名单目录；路径校验是唯一的文件系统边界 |
| 子进程 → 网络 | unshare --net 创建无网命名空间，阻断所有网络访问 |
| 子进程 → 宿主机资源 | rlimit 硬限制防止 CPU/内存/进程/文件耗尽 |
