# loopAI

## 这是什么

一个基于 ReAct（Reasoning + Acting）范式的 AI Agent 框架。核心不是 agent 循环本身，而是围绕循环的工程化基础设施（harness）：工具抽象、上下文组织、错误恢复、执行边界。附带 Web 前端用于实时展示 agent 的思考链路、工具调用和状态变化。

**v1.0 已交付：** 单 Agent ReAct 循环 + 工具系统 + 上下文管理 + 韧性恢复 + Web 可观测性 Dashboard + Agent-as-Tool 多 Agent 协作 + Chat 对话模式。首个业务验证场景为磁盘空间诊断与清理。

**v1.1 方向：** 动态工具系统——Agent 能自主编写 Python/Bash 代码，经用户确认后动态注册为新工具，运行时隔离在沙箱内。仍以磁盘诊断为验证场景。

## 核心价值

让 AI Agent 不仅"能跑"，而且可靠、可观测、可扩展——从 harness 设计的深度思考出发，构建值得信任的 agent 系统。

## 当前里程碑: v1.1 动态工具系统

**目标:** Agent 能在沙箱内自主编写 Python/Bash 代码，经用户确认后动态注册为新工具，运行时隔离受限

**目标功能:**
- Agent 自主提议创建工具 → 前端确认（代码展示 + 持久化级别 + 目录权限）
- 两阶段验证：语法检查（ast.parse / bash -n）+ Agent 自测
- 三级持久化：会话级 / 沙箱级 / 项目级
- 运行时沙箱限制：默认隔离子目录、禁止联网、独立超时
- 工具管理：前端"动态工具"tab，查看代码 + 禁用/启用 + 删除
- 工具更新：Agent 修改已有工具 → diff 展示 → 用户确认
- 命名冲突：新旧代码对比 → 用户选择覆盖或拒绝
- 工具发现：system prompt 注入概要 + list_tools 查询详情
